## Amazon AppStream 2.0 (now Amazon WorkSpaces applications)

[Streams apps and can deliver nonpersistent desktops](https://aws.amazon.com/workspaces/applications/). Choose to provide a centrally managed application to users without installing it locally. You still manage access to images, applications, and sessions; streaming capacity and usage affect cost.

## Amazon WorkSpaces

[Virtual desktops](https://aws.amazon.com/workspaces/) for remote users. Choose WorkSpaces Personal when a user needs a persistent, assigned desktop rather than only one streamed application. Desktop selection, session usage, and access settings remain customer decisions.

## Amazon WorkSpaces Secure Browser

Provides remote, isolated browser sessions for web apps instead of a full desktop. Useful for an existing organization that wants web content rendered off the local device. [Closed to new customers October 29, 2026](https://docs.aws.amazon.com/workspaces-web/latest/adminguide/workspaces-secure-browser-maintenance-mode.html); existing customers can continue using it. AWS documents WorkSpaces Applications with a self-managed browser image as one alternative, not a new name for Secure Browser.
