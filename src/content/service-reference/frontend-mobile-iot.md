## AWS Amplify

[Tools for building web and mobile apps](https://aws.amazon.com/amplify/), including managed web frontend hosting and integration with backend capabilities such as authentication. Choose for a frontend team shipping a web app, not for a generic virtual server or app store submission. You still own application code and access settings.

## AWS IoT Core

[Secure device connectivity and messaging](https://aws.amazon.com/iot-core/). Choose to receive telemetry from sensors and route it to AWS services, not to stream an app to users or physically manage equipment. Device identities, permissions, and message volume matter for security and cost.
