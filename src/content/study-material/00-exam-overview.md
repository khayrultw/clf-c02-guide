# CLF-C02 exam overview

| Exam measure | Official format |
|---|---|
| Length and time | 65 questions in 90 minutes |
| Scoring | 50 scored, 15 unscored; the unscored questions are not marked |
| Single answer | One correct response from four options |
| Multiple response | Two or more correct responses from five or more options |
| Unanswered items | Count as incorrect; no guessing penalty |
| Passing score | 700 on a 100–1,000 scaled score, not a raw 70% |

The exam is scored overall; there is no separate passing score per domain. Pace yourself across all questions. Answer every item and return to difficult ones if time permits.

The official guide lists **19 tasks**. At practitioner depth, explain an idea in plain language, choose the closest service for a requirement, and explain why a close alternative does not fit. You do not need to write code, implement solutions, design cloud architectures, troubleshoot them, or run performance tests for this blueprint.

## Practice versus the official exam

Each package practice set has 50 questions: 12/15/17/6 by domain. Multiplying each published weight by 50 gives whole numbers, so rounding is not needed. The fixed question format split is not an official AWS statistic. Never use a practice score to predict a scaled AWS result.

AWS recommends the [Official Practice Question Set](https://skillbuilder.aws/learn/E4W52ZKK6P/official-practice-question-set-aws-certified-cloud-practitioner-clfc02--english/RJSZKD3MG3) to get familiar with question style. The [Skill Builder preparation page](https://skillbuilder.aws/category/exam-prep/cloud-practitioner-foundational-CLF-C02) and activity URL were reachable, but signed-in activity contents were not verified here. No AWS assessment text was used. The public exam guide supplies format and scoring facts.
