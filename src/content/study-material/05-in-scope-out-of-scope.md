# What to study at practitioner depth

| Category | What you should do |
|---|---|
| Official task statements | Explain the required concepts and choose services in short scenarios. Start with the [exam overview and domain lessons](00-exam-overview.md). |
| Published service and concept lists | Recognize purpose and a common use. Do not memorize console steps, API calls, or price tables. |
| Helpful supporting information | Use examples, aliases, and comparisons to understand the decision. Do not assume every supporting detail is an exam objective. |
| Explicitly out of scope | Skip the services AWS explicitly excludes and the excluded implementation job tasks. Example: AWS CLI is listed; AWS CloudShell is explicitly excluded. |
| Missing from the service list | Absence alone does not settle scope. Verify it against the task statements and other official scope material before treating it as assessable. |

The [instructor inventory](../question-reports/blueprint-coverage.md) enumerates the named services, published concepts, and explicit exclusions separately. A listing measures coverage of the AWS blueprint; it does not predict live exam items.
